## 추가·변경 사항

원본 게임(PS2판 「機神咆吼デモンベイン」, SLPM-65491) 대비 이 한국어 패치가 바꾸거나 더한 것을 정리했다.
근거는 괄호 안에 파일 이름과 릴리스 태그로 단다. 확실하지 않은 것은 「(추정)」이라고 적었다.

### 대상 판본

- PS2 일본판 「機神咆吼デモンベイン」(SLPM-65491, NTSC, VER 1.02) DVD ISO. 원본 크기는 4,609,081,344바이트, SHA-256은 `4d249a10…43523f`다(`FINDINGS_KO.md`, `release/pkg/읽어보기.txt`).
- 패치한 ISO는 PCSX2로 실행한다(`읽어보기.txt`). 실기에서는 시험하지 않았다.
- 결과 ISO의 SHA-256은 `e1a284e386bef9c72a8057c05d9a10c36fa9714a213532de12366f04fb1f0377`이다. xdelta 파일의 SHA-256은 `6488cab6…`이다(`릴리스_v3.md`).

### 번역 범위

- **원문**: 일본어 PS2 대본(`SCRIPT/SCRIPT.PCK`, 396엔트리, 니트로플러스 태그 스크립트)을 기준으로 했다.
- **본문(대사·지문 전체)**: 기존 팬 번역 「참마대성 데몬베인 간이한패」를 바탕으로 했다(`FINDINGS_KO.md` 「선번역본」).
  - 간이한패는 PC 18금판 「斬魔大聖デモンベイン」(NSS 엔진)용이다. 그 번역 문장 65,372줄을 회수해 PS2 대본에 줄 단위로 맞췄다.
  - 맞춘 뒤 원문 기준으로 다시 판정했다. 판정본은 KEEP 27,871 / FIXED 18,845 / NEW 790 / HOLD 40이다(`재개.md`, 2026-09-05 v2).
  - 그 위에 코덱스가 161개 ID를 교정한 09-05 교정본(`translation-codex-repair-20260905/aligned_final.tsv`)을 v3에 넣었다. 이 표의 상태 열은 KEEP 27,829 / FIXED 18,927 / NEW 790 / EXTRA 3,758이고 HOLD는 0이다.
  - 콘솔판에서 개작된 씬은 기존 후보가 어긋나 있어 원문만 보고 새로 썼다(`work/판정지침.md`).
- **PS2판에만 있는 추가 시나리오(새 번역, 2026-11-01)**: 팬 패치에 없던 부분이라 새로 번역했다(`work/added/ko/*.tsv`, `릴리스_v3.md`).
  - 7장 끝에 붙은 이타콰·크투가 이야기 6장면(D0751~D0756)
  - 루리 엔딩에서 「아니……아직이다!」를 골랐을 때 이어지는 진엔딩 갈래(ep_ruri02a). 화면에 새로 나오는 것은 1078줄 이후 약 60조각이다. 앞부분은 ep_ruri01과 같은 내용이라 기존 번역으로 보인다.
  - 합쳐서 946조각이다.
  - 팬 패치에 없던 단일 줄 4개(`_singles.tsv`)도 새로 옮겼다.
- **선택지 57개(v3에서 처음 번역)**: 선택지 글은 `<CHOICE TEXT="…">` 태그 속성이라 v2까지 한 번도 바뀌지 않았다. 캐리어 글꼴 탓에 깨져 보였을 것이다. 주석 처리된 4개는 그대로 두었다(`work/added/ko/_choices.tsv`).
- **번역 규칙**: 전작 「기신비상」 지침과 통일했다. 알은 「이 몸 / 그대」로 말하고, 아컴·미스캐토닉 같은 표기를 쓴다. 대사 안에서는 그/그녀를 쓰지 않는다. 인물별 말투를 정했다(`work/판정지침.md`, `work/ref/glossary_curated.tsv`).
- **아직 일본어로 남은 것**:
  - 메뉴 글자: 실행 파일(ELF) 안의 일본어 391종. 타이틀·세이브·설정·메모리카드 안내 등이다. ELF 글꼴이라 깨지지는 않는다.
  - 그림 속 글자: `PARTS.PCK` UI 그림 252장과 일부 CG
  - 개발용 디버그 대본(`chkcglib.txt`, `start.txt`의 BGM 점검 갈래, `bgm.txt`, `test.nps`, `menu2.nps`). 정상 진행에서는 나오지 않는다. 일본어가 남은 조각 760개가 모두 여기에 있다(`릴리스_v3.md`).
- **보류했던 장면**: v2(09-05) 때 D1212의 한 장면 40줄(`1212_02`)은 Claude가 번역하지 않아 일본어 원문 그대로였다(`재개.md`). v3 입력인 09-05 교정본에는 HOLD가 0이고, D1212 136줄 모두 한국어 칸에 일본어가 없다. 누가 어떻게 채웠는지는 저장소에서 확인하지 못했다(추정: 코덱스 교정 단계).

### 화면·글꼴

- **한글 캐리어 글꼴**: 게임 글꼴(`FONT/FONT.PCK`, JIS X 0208 비트맵 79쪽)에서 쓰지 않는 한자 칸에 한글 2,361음절을 그려 넣었다. 대본에서는 한글을 그 한자 코드로 바꿔 싣는다(`FINDINGS_KO.md` 5절, `work/ref/ps2_carrier_map.json`, `assets-ko/`). 제작사도 84구에 패드 아이콘을 넣는 같은 수법을 쓰고 있었다.
- **반각 기호 전각화(v3)**: 엔진은 반각 중 공백, `!`, `?`, `' . _ +`, 영숫자만 전각으로 바꿔 그린다. 나머지 기호(`, ~ - ( ) : % & = $` 등)는 글자 칸이 채워지지 않아 깨졌다. 그래서 빌드에서 전각으로 바꿨다. `~` 838곳, `-` 221곳, `( )` 120곳 등이다. 낱자 ㄱ 1곳은 「기역」으로 썼다(`릴리스_v3.md`).
- 화면 해상도나 그래픽 개선 기능은 없다.

### 버그 수정 (이전 판 대비)

- **글꼴 한자 깨짐(v3, 2026-11-01)**: 8월 v2부터 캐리어 2,361음절 중 732음절(31%)이 한자로 나왔다. 예를 들어 「젠장」이 「任장」으로 보였다.
  - 원인: 옛 그리기 도구가 칸 번호를 한 칸 밀어 그렸다.
  - 고침: `release/repaint_font_v3.py`로 각 한글을 제 칸(칸 = JIS 점)에 다시 그렸다(→ `font_ko_v3`). 예전에 맞던 1,629음절은 그림 바이트가 같다. 대본은 그대로이고 `FONT.PCK`만 바뀌었다(`릴리스_v3.md` 「글꼴 수리」).
- **빌드 도구 고침(v3, `release/build_release.py`)**:
  - 한 줄에 단위가 여럿(`<K>`)이면 앞 단위를 덮어쓰던 것을 고쳤다.
  - 여러 줄 단위에서 뒷줄 일본어가 남던 것을 고쳤다(7,786줄 정리).
  - 파일 경계를 한 단위로 묶은 10곳을 나눴다.
  - 다시 풀어 대조하는 검사를 넣었다.
  - 결과는 단위 46,015 배치에 못 맞춘 단위 0, 캐리어 없는 음절 0, 파일당 81,920바이트 상한 초과 0이다.
- **v2 빌드 고침(2026-09-04~05)**: 원문 `<R>` 루비 태그 제거, `<K>` 분할 단위 순서 처리, 태그 잔여물 줄 건너뛰기(`재개.md`).

### 설치·제거 방식

- 릴리스 v3의 `패치하기.bat` 위로 직접 추출한 원본 ISO를 끌어다 놓는다. 같은 폴더에 「(원래 이름) (Korean v3).iso」가 생기고, 원본 ISO는 바뀌지 않는다. xdelta3 3.2.0이 들어 있다(`release/pkg/패치하기.bat`, `읽어보기.txt`).
- 원본 크기가 다르면 경고만 하고 그대로 패치한다.
- `SCRIPT.PCK`는 원본보다 작게 만들어 ISO 안 제자리에 덮어쓴다. 그래서 ISO 크기는 그대로다(`릴리스_v3.md`).
- 제거는 원본 ISO를 그대로 쓰면 된다. 패치는 새 파일을 만들 뿐이다.
- **점검용 ISO(배포 안 함)**: `--check-menu`로 빌드하면 새 게임 시작 때 선택지 셋이 뜬다. 7장 추가 장면, 루리 진엔딩 갈래, 처음부터 시작이다. 정식판과 다른 곳은 `D0100.txt` 하나뿐이다(`릴리스_v3.md`).

### 알려진 문제

- 화면 확인을 하지 않았다. 빌드와 해시 검증만 했다(릴리스 v3 노트). 사용자가 볼 곳은 다음과 같다.
  - 7장 추가 장면
  - 강조점 두 줄(D0754:175, D0755:204)
  - 선택지
  - 루리 엔딩 회상
- 메뉴 글자와 그림 속 글자는 일본어 그대로다.
- 코덱스 의미 검수는 47,366 ID가 미검수 상태다. 열린 질문 OQ-001(字祷子 표기), OQ-002(치아키 사투리), OQ-004(루비 병기), OQ-006(사령비법)은 기존 문장 그대로 두었다.
- 병렬 판정(에이전트 약 215개) 탓에 씬 사이 표기와 문체가 갈렸을 수 있다(`재개.md`).
- 자동 줄바꿈과 대사창 넘침은 화면으로 확인하지 않았다(`FINDINGS_KO.md` 「아직 확인 못 한 것」).
- 배포 때 원 번역(「참마대성 데몬베인 간이한패」 제작진)의 표기와 허락을 확인해야 한다.
